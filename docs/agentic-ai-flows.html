Public Entry Points

Profiler

Get-ExcelDatasetSummary

Reads CSV, TSV, or workbook sources and returns compact metadata, sample rows, inferred types, roles, and suggested formats.

Planner

New-ExcelReportPlan

Creates a constrained plan from a prompt and dataset summary using PSAISuite or local deterministic defaults.

Renderer

Invoke-ExcelReportPlan

Builds the workbook from the plan: data tables, charts, pivots, analysis sheets, summaries, and formatting.

Prompt workflow

Invoke-ExcelPrompt

One-call path for prompt to workbook. It profiles, plans, and renders.

Script generator

New-ExcelReportScript

Creates a reusable PowerShell script, validates it, and falls back to deterministic script generation when needed.

Agent workflow

Invoke-ExcelAgent

Generates and runs the reusable script, with runtime fallback if model-written code fails.

Main Flows

1. Dataset Profiling

Compact facts for prompts, planning, and deterministic reports.

Inputs

  • CSV, TSV, or workbook path
  • Optional worksheet names
  • Sample and analysis row limits

Steps

  • Load sources
  • Infer type and role
  • Capture counts, samples, formats

Outputs

  • DatasetSummary object
  • Optional JSON
  • Input to planning and script flows
Get-ExcelDatasetSummary -Path .\sales.csv

2. Prompt to Plan

Natural language becomes a constrained, executable report plan.

Inputs

  • DatasetSummary
  • Prompt
  • Model or -NoAI

Steps

  • Build local default plan
  • Ask PSAISuite for JSON if enabled
  • Apply prompt intent defaults

Outputs

  • Tables
  • Charts and pivots
  • Conditional formats
  • Analysis sheets
$summary = Get-ExcelDatasetSummary .\sales.csv
$plan = New-ExcelReportPlan -DatasetSummary $summary -Prompt "Create a report with data bars and a line chart" -NoAI

3. Plan to Workbook

ImportExcel turns the plan into a real .xlsx file.

Inputs

  • Plan object or JSON
  • Source path
  • Dataset summary
  • Output path

Steps

  • Write data tables first
  • Add charts and analysis sheets
  • Add pivots and conditional formatting
  • Put Summary and Column Profile last

Outputs

  • Workbook path
  • Worksheet list
  • Plan and dataset summary
$plan | Invoke-ExcelReportPlan -Path .\sales-report.xlsx -SourcePath .\sales.csv -DatasetSummary $summary -Force

4. Prompt to Workbook

The ergonomic path for creating a report from a plain-language ask.

Inputs

  • Path
  • Prompt
  • OutputPath
  • -FallbackToDefault or -NoAI

Steps

  • Profile
  • Plan
  • Render

Outputs

  • Workbook
  • Render result
Invoke-ExcelPrompt -Path .\sales.csv -Prompt "Create an executive dashboard with a pie chart" -OutputPath .\sales-report.xlsx -FallbackToDefault -Show

5. Prompt to Script

Creates reusable automation the user can inspect and rerun.

Inputs

  • Path
  • Prompt
  • Workbook output path
  • Script path

Guardrails

  • PowerShell parse checks
  • Command and parameter validation
  • Missing argument detection
  • EPPlus direct styling rejection

Outputs

  • Reusable .ps1
  • UsedAI flag
  • Dataset summary
New-ExcelReportScript -Path .\sales.csv -Prompt "Create the data in a table and use data bars" -OutputPath .\sales-agent-report.xlsx -ScriptPath .\build-sales-agent-report.ps1 -FallbackToDefault

6. Agent Workflow

Script generation plus execution, with fallback at validation and runtime.

Inputs

  • Path
  • Prompt
  • OutputPath
  • ScriptPath
  • -ScriptOnly optional

Steps

  • Generate script
  • Run script
  • Regenerate deterministic script if AI code fails

Outputs

  • Workbook
  • Reusable script
  • Result metadata
Invoke-ExcelAgent -Path .\sales.csv -Prompt "Create the data in a table, use data bars, highlight top 3, and create a line chart" -OutputPath .\sales-agent-report.xlsx -ScriptPath .\build-sales-agent-report.ps1 -FallbackToDefault -Show

Data Contracts

DatasetSummary

Path, file name, source list, row and column counts, inferred column metadata, sample rows, and suggested formats.

ReportPlan

Workbook title, summary settings, tables, charts, pivots, conditional formats, and optional analysis sheets.

AgentResult

Workbook path, script path, source path, UsedAI flag, model, script-only flag, and script execution result.

Safety Model

AI can try

The model can plan JSON or generate a full PowerShell report script through PSAISuite.

PowerShell decides

Plans and scripts are parsed, constrained, validated, rendered, and when necessary replaced by deterministic fallback behavior.

The strongest pattern in this module is not "AI writes arbitrary Excel." It is "AI orchestrates trusted ImportExcel primitives while deterministic functions provide the facts and workbook mechanics."
